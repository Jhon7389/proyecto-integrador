# JVMA TECH & GAMING

**Tienda web de tecnología, videojuegos y coleccionables.**

## Descripción
JVMA TECH & GAMING es un proyecto personal y académico desarrollado para aplicar conocimientos de Diseño Web durante la formación en Ingeniería de Sistemas.

La página presenta una tienda virtual con productos de tecnología, videojuegos, accesorios y coleccionables.

## Funcionalidades
- Página de inicio.
- Catálogo y categorías de productos.
- Búsqueda y filtros.
- Detalle de productos.
- Carrito de compras.
- Simulación de compra.
- Panel administrativo de demostración.
- Registro y edición de productos.
- Gestión de inventario.
- Historial de ventas de demostración.
- Contacto mediante WhatsApp.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Estructura
- `index.html`: página principal.
- `pages/`: catálogo, producto, carrito y administración.
- `css/styles.css`: estilos y diseño adaptable.
- `js/main.js`: funcionalidades e interactividad.
- `assets/img/`: recursos gráficos.

## Ejecución
Descargar o clonar el repositorio y abrir `index.html` en un navegador web.

## Consideraciones técnicas
El proyecto utiliza LocalStorage para guardar datos en el navegador. No cuenta con una base de datos centralizada, pasarela de pagos ni autenticación segura de servidor. Las operaciones de compra y administración son demostrativas.

## Propósito académico y personal
Este proyecto fue desarrollado principalmente como una iniciativa personal de aprendizaje y aplicación práctica de conocimientos de HTML, CSS y JavaScript. No pretende ser una plantilla para futuras evaluaciones, sino una base para experimentar, practicar y fortalecer habilidades de desarrollo web.
