# Práctica HTML5: La tecnología en nuestra vida cotidiana

## Descripción
Esta práctica consiste en desarrollar una página web básica utilizando HTML5 para explicar la importancia de la tecnología en nuestra vida diaria.

## Objetivo
Aplicar etiquetas HTML5, encabezados, párrafos, listas, imágenes y enlaces de navegación.

## Estructura del proyecto
- `index.html`: página principal.
- `pages/nosotros.html`: información sobre nosotros.
- `pages/contacto.html`: página de contacto.
- `assets/img/`: imágenes utilizadas.
- `assets/icons/`: carpeta para iconos.
- `assets/fonts/`: carpeta para fuentes.
- `css/`: hojas de estilos.
- `js/`: archivos JavaScript.

## Tecnologías utilizadas
- HTML5
- Git
- GitHub
